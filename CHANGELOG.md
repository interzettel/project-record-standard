# Changelog

## 0.4.1

This release packages the completed standard for pinned adoption. Record contract 0.2.0 remains compatible. Publication time, exact revision and asset hashes belong to the GitHub release and authored delivery record.

- Shared scope vocabulary, work breakdown, milestone gates, roadmap relationships and exact percentages across README and interactive views. Existing projects keep their branding and source identities.
- History bridges explain work completion separately from scope growth. Change fragments, release readiness, publications and deployment observations have distinct records.
- Eleven agent workflows cover new setup, existing adaptation, scope, progress updates, status, GitHub mappings, delivery, presentation, operations, routing and accessibility. The additive installer previews changes, preserves existing instructions and supports repeat/recovery.
- Setup includes the portable L0–L5 readiness assessment and ten evidence dimensions, with separate R0–R4 task-risk and authority records.
- Accessibility fixes preserve announcements and focus through search/filter updates, expose selected list state and improve default contrast. Scoped WCAG 2.2 review, observed native zoom and owner-confirmed Narrator evidence retain their limits.
- Python/browser rounding agrees at half-tenths; 13/16 displays 81.3%. Offline automation, public hash boundaries, reusable CI and Pages are verified independently.
- Consolidated current documentation, retained dated planning history, deterministic source archive, SHA-256 manifests and extraction/install smoke checks support repeatable adoption.

The bounded implementation is 18/18 required items and 4/4 milestone gates. Individual repository migrations are a later phase. This completion does not establish a readiness grade or full WCAG conformance.
