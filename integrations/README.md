# Local runtime adapter pilot

This unreleased POSIX pilot connects an explicitly prepared work-result ticket to documented Codex and Claude Code hook envelopes. It is not an installed or supported unattended integration. See [the adapter contract](../standards/RUNTIME-ADAPTERS.md) for preparation, configuration, trust review, recovery and the remaining live-session gate.

`tools/run_runtime_adapter.py` owns transport only; `tools/run_reconcile_event.py` calls the existing shared reconciler. Neither interprets assistant prose, edits runtime permissions, submits GitHub updates, launches inference or selects a professional role.

The JSON files here are synthetic envelope examples for inspection, not native receipts or configuration to install unchanged.
